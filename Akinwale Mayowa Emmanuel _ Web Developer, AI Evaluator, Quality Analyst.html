I find bugs and confirm the fixes

Because I write code, I know where bugs hide and how to describe them so they get fixed. These are real issues I traced and resolved on my own projects:

  • Database requests timing out on some Wi-Fi and hotspot networks: traced to DNS resolution and fixed in the Node server.
  • Blocked cross-origin image and API requests: fixed with the right Helmet and CORS configuration.
  • Page refreshes returning 404 on a deployed React app: fixed with Vercel rewrite rules.
  • Write bug reports with steps to reproduce and expected versus actual results, then retest fixes and run regression checks.
  • Use Postman for API requests and Chrome DevTools for network calls, console errors and layout issues.
